# Zaiblify v0.1 plan

## Objective

Build an offline Flutter Android app that transforms selected text into Unicode formatting and font styles.

## Included

- Quick splash screen
- First-run three-page tour
- System theme by default
- Light and dark themes
- Floating glass-inspired navigation container
- Home screen
- Styles gallery
- Settings screen
- Bold, italic, bold italic, underline, strikethrough, monospace
- Unicode font styles: sans bold, sans italic, serif, serif bold, serif italic, script, double-struck, fraktur, small caps, fullwidth
- Fun styles: reverse, upside-down, bubble
- Android text-selection integration through `ACTION_PROCESS_TEXT`

## Excluded

- AI features
- Login and accounts
- Cloud sync
- Analytics
- Subscriptions
- Remote APIs
- History/database
- Real font installation
- Font marketplace
- Image export
- iOS support

## Milestones

### M1: UI foundation

- Flutter project builds
- Theme system works in system, light, and dark modes
- Splash and tour work
- Tour completion is persisted
- Shell navigation works

### M2: Formatting engine

- Unicode maps are isolated from UI
- Unsupported characters remain unchanged
- Whitespace, punctuation, emoji, and line breaks are preserved
- Unit tests cover each style

### M3: Android integration

- Zaiblify is visible in supported text-selection menus
- Selected text is received
- User chooses a style
- Transformed text is returned to the source app
- Cancellation and unsupported apps are handled gracefully

### M4: Quality

- Test Chrome, WhatsApp, Telegram, Gmail, Google Keep, Google Docs, and a native text field
- Verify light/dark contrast
- Verify small screens and text scaling
- Run `flutter analyze` and tests

## Definition of done

A user can select text in at least 3–5 common Android apps, open Zaiblify, choose a style, and receive transformed text without an account or internet connection.
